# integrations/ — кастомные интеграции Bathys

Здесь живут интеграции для харнессов, которым мало стандартной записи MCP-сервера:
скрипты, оболочки, готовые конфиги и дроп-ины. Стандартный автопат (`bathys
install`) покрывает 14 клиентов из их собственных конфигов; этот каталог —
для кастомной механики.

## Конвенция

Каждая интеграция — подкаталог `integrations/<harness>/`:

```
integrations/<harness>/
├── README.md        # что это, когда нужно, установка по шагам
├── install.*         # установщик (если интеграция больше ручной вставки)
└── assets/           # конфиги, скрипты, промпты, расширения
```

Правила:

- интеграция не тянет зависимостей сверх самого Bathys (только stdlib);
- установщик идемпотентен и делает бэкап перед записью — как `bathys install`;
- каждый README фиксирует формат конфига по первоисточнику (ссылка на доки
  харнесса) и дату проверки;
- сюда попадают только кастомные пути; обычные конфиги правит `bathys install`.

## Содержимое

| Интеграция | Что даёт |
|---|---|
| [`hermes/`](hermes/) | установщик для Hermes Agent: `mcp_servers` в `~/.hermes/config.yaml` + субагент в `~/.hermes/agents/`; обходит случай, когда у Hermes нет конфига вообще (создаёт по канону его доков) |
| [`pi/`](pi/) | дроп-ин для Pi (badlogic pi-mono): у Pi нет MCP-конфига — интеграция это правила для `AGENTS.md` проекта + скилл-каталог Bathys |
| [`zcode/`](zcode/) | комплект для zcode: MCP-конфиг, субагент `bathys-researcher`, скиллы и ссылка на дроп-ин — всё, что ставится копированием |
