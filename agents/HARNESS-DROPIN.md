# Bathys — блок для файла инструкций харнесса

Скопируй блок ниже (от `## Веб-доступ…` до конца файла) в файл инструкций
своего агента: ZCode — `AGENTS.md` (глобальный или проектный); Claude Code —
`CLAUDE.md`; Cursor — `.cursor/rules/*.mdc`; generic — системный промпт.
Блок самодостаточен: после него агент выбирает инструменты Bathys нативно и
не ходит в интернет мимо них.

Опционально (рекомендуется): скопируй `agents/bathys-researcher.md` в каталог
субагентов (zcode: `~/.zcode/agents/`; claude code: `.claude/agents/`) и
скиллы из `agents/skills/` — получишь профиль, заточенный под глубокий
ресёрч через Bathys.

## Веб-доступ: всегда через Bathys (локальный поисковый сервис, MCP)

Поиск, чтение страниц и исследования — только через инструменты Bathys.
Сторонние web-инструменты не использовать: у Bathys свои дистилляция под
запрос, токен-бюджеты, кэш и метрики.

Выбор инструмента:

- исследовательский вопрос («что/как/почему/сравни») → `deep_research(query)`
  — ищет, читает топ-источники, возвращает дистиллят под запрос;
- нужны только ссылки → `web_search(query)`; для программы/скрипта —
  `web_search(query, as_json=true)`;
- один известный URL → `read_url(url, query=…)`; несколько (до 10) →
  `read_urls(urls, query=…)` — общий бюджет, битая страница стоит строку.

Правила:

1. `query` — вопрос, не мешок ключевых слов: дистиллятор отбирает пассажи по
   смыслу запроса. Максимум 3 итерации на формулировку, дальше — смена угла
   (термины из найденного, другой язык, `category`).
2. Ключевой факт — два независимых домена; один источник — «по данным одного
   источника»; конфликт — показать обе версии с URL.
3. Каждый нетривиальный факт в ответе сопровождай URL из секций Bathys.
4. Свежесть — `time_range` (`day`|`week`|`month`|`year`). `refresh=true` дорог
   (ломает кэш): только при протухшем кэше — `cache HIT` при устаревших
   данных — и один раз на главный источник.
5. Сигналы: `(not fetched — …)` — источник не прочитан, работай с остальными;
   `robots-refused` — сайт запретил чтение, уважай; `No results … tried N
   engine sets` — помоги формулировкой (синонимы, язык); `Answer:` — мгновенный
   справочный ответ, спорное подтверди источником.
6. Футер `[bathys: …]` — статистика (сжатие ch, `cache HIT`/`MISS`, сек);
   не цитируй его пользователю.

Готовые стратегии — MCP-промпты `bathys_deep_research`, `bathys_source_audit`,
`bathys_fresh_scan`: бери как стартовый шаблон плана.
