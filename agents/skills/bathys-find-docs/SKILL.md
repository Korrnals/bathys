# Bathys Find Docs — документация библиотеки под вопрос

## Когда применять

- Вопрос о библиотеке/фреймворке/API/CLI: сигнатура, конфигурация,
  поведение опции, версия, поддержка («как в FastAPI сделать X», «какие
  аргументы принимает react useEffect», «настраивается ли nginx
  client_max_bodySize»).
- Даже если либа известная и ответ «кажется очевиден»: модель могла
  выучить устаревшую сигнатуру — `library_docs` стоит дешевле, чем
  неверный ответ.
- Не для: рефакторинг, бизнес-логика, код-ревью; общие концепции без
  конкретной библиотеки («что такое SSR»); вопросы, отвечаемые из
  локального кода и контекста.

## Процедура

1. **Один вызов.** `library_docs(library, query=…)` — без предварительного
   поиска: резолв док-сайта (индекс → живой web_search → GitHub-slug)
   и дистилляция уже внутри. `query` — конкретный вопрос («что искать в
   доках»), не задача целиком.
2. **Дисциплина query.** Один концепт на запрос; конкретика вместо одного
   слова. Хорошо: «how to configure rate limiting per user», «useEffect
   dependency array cleanup function». Плохо: «auth», «hooks», «как
   сделать приложение». Уточняющий вопрос по той же либе — снова
   `library_docs` с новым `query`: сырец в кэше, повтор почти мгновенный
   и бесплатный.
3. **Дистиллят навигационный или пустой** (меню доксайта вместо
   содержания, пустые секции): переформулируй `query` терминами из
   заголовков дистиллята — или уйди в `deep_research` по «{library}
   {тема} documentation».
4. **Максимум 3 попытки** на один вопрос: переформулировка `query` →
   `deep_research` → дальше смена угла, не шестой заход.
5. **Отказ-паттерн.** `library_docs` не смог (сеть, «не удалось найти
   документацию», пустой дистиллят после 3 попыток): скажи об этом явно
   и отвечай из памяти с оговоркой — «ответ из тренировочных данных,
   может быть устаревшим; актуальность не проверена».
6. **Ответ с цитатами.** URL док-сайта — в шапке ответа `library_docs`;
   цитируй его у нетривиальных фактов. Локальные квот нет: повторы
   бесплатны — уточняй ответ запросом, а не догадкой.

## Выход

- Ответ на вопрос по документации с URL первоисточника; при отказе —
  ответ из памяти, явно помеченный как потенциально устаревший.

## Анти-паттерны

- Ответ о сигнатуре/конфигурации из памяти без вызова `library_docs` —
  самый частый источник устаревших API-ответов.
- `web_search`/`deep_research` первым для док-вопроса: медленнее и
  размытее, чем `library_docs` в точку доксайта.
- `query` = одно слово («hooks», «auth») или вся задача пользователя
  одним куском.
- Молчаливый ответ из памяти после фейла `library_docs` без оговорки
  об устаревании.
