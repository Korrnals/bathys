# Роадмап Bathys

Сопутствующие документы: [charter.md](charter.md) · [features.md](features.md) · [competitive.md](competitive.md).

Как читать этот роадмап: версии описывают **форму работы, а не обещание дат**.
Ёмкость — один мейнтейнер в вечернем режиме; каждая версия явно называет, что
откладывается, чтобы освободить место. Приоритеты P0/P1/P2 определены в
[features.md](features.md): P0 — критично, P1 — важно, P2 — позже.

| Горизонт | Версия | Тема |
|---|---|---|
| Now | v0.2 | Качество выдачи |
| Next | v0.3 | Паритет с Tavily |
| Later | v0.4 | Эксплуатация |
| Horizon | v1.0 | Стабильный релиз |

## v0.2 «Качество выдачи» (Now)

**Выпущена 2026-09-06 как `0.2.0`** (см. [CHANGELOG](../../CHANGELOG.md)); на пост-релизном наблюдении остался один критерий — недельная доля пустых выдач < 10%.

**Цель.** Сделать выдачу устойчивой: 9 из 10 запросов возвращают полезные источники,
даже когда поисковики капризничают и показывают капчи.

**Состав.** F-101 (P0) ✅, F-102 (P1) ✅, F-103 (P2) — позже, F-104 (P2) — позже. Досрочно поставлены: F-105/F-106 (честные футеры), F-202 (`refresh`), F-301 (вежливый режим, из v0.4), F-201 (`read_urls`, из v0.3), F-302 (пин SearXNG), юнит-часть F-401 (49 тестов). См. [features.md](features.md).

**Критерии приёмки.**

- [x] На прогоне из 20 разнотипных запросов не менее 18 возвращают ≥ 3 непустых хитов. — **2026-09-06: 19/20** (`scripts/acceptance_v02.py`).
- [x] При искусственно заблокированном одном движке (пустой ответ) результат приходит из остальных без падения вызова. — live-доказательство 2026-09-06: `startpage` был недоступен весь прогон (пойман `bad_engines`), 19/20 запросов прошли; retry-логика покрыта юнит-тестом с мок-заглушкой (`tests/`).
- [x] Повторный идентичный запрос отдаётся из кэша за 0,0 с (базовая линия F-004 сохранена). — футер `cache HIT · 0.0s` в смоках.
- [ ] За неделю реального использования доля пустых выдач ниже 10%. — ждёт недельного окна живой работы (мейнтейнер).

**Риски.** Ротация движков при блокировке может спровоцировать ещё больше капч —
ротация обязана идти с паузами (частично перекрывается с F-301); автотестов ещё нет,
поэтому приёмка выполняется вручную по прогону.

**Что откладывается.** Весь паритет с Tavily (F-201–F-204), вся эксплуатация
(F-301–F-305) и релизная упаковка (F-401–F-405) — чтобы не распылять вечернюю ёмкость.

## v0.3 «Паритет с Tavily» (Next)

**Выпущена 2026-09-06 как `0.3.0`** (поставлено одной итерацией с v0.4.0 — см. [CHANGELOG](../../CHANGELOG.md)).

**Цель.** Закрыть сценарии, ради которых платят за Tavily: пакетное извлечение страниц,
контроль свежести и качественная выдача через API-движки.

**Состав.** F-203 (P1) ✅, F-204 (P2) ✅. F-201 (`read_urls`) и F-202 (`refresh`) поставлены досрочно 2026-09-06 вместе с v0.2.

**Критерии приёмки.**

- [x] `read_urls` читает пакет из 5 URL одним вызовом с общим бюджетом символов и возвращает пометки по каждой ошибке отдельно. — **2026-09-06: `batch 5 urls · 4/5 ok` (один URL отдал HTTP 500 → отдельная строка `(not fetched — …`), `330857 ch → 1248 ch`**.
- [x] Флаг `refresh=true` перекачивает страницу и выдачу, игнорируя живой кэш, и обновляет TTL. — поставлено в v0.2, покрыто параметром во всех инструментах.
- [x] API-движок (Brave Search API) включается одним env-ключом и появляется в выдаче с маркером движка. — структурно: `BATHYS_ENGINE_BRAVE_KEY` → `render_settings` пишет движок `brave` в настройки нативного SearXNG; хиты несут маркеры движков. Live-проверка с реальным ключом — за мейнтейнером (ключа у проекта нет); docker-режим — правка settings вручную.
- [x] [competitive.md](competitive.md) обновлён: паритет с Tavily Extract подтверждён или честно описан как частичный. — обновлено 2026-09-06: Extract-паритет полный (`read_urls`+`read_url`), Search-паритет — честно частичный (метапоиск против платного индекса).

**Риски.** API-ключи — частичная уступка принципу «ноль облачных зависимостей»:
решение — строго опционально, выключено по умолчанию. Пакетное чтение удлиняет
один вызов: общий бюджет символов и таймаут на пакет обязательны.

**Что откладывается.** Пин релиза SearXNG, robots.txt и наблюдаемость (F-301–F-305)
остаются в v0.4; упаковка — в v1.0.

## v0.4 «Эксплуатация» (Later)

**Выпущена 2026-09-06 как `0.4.0`** (одной итерацией с v0.3.0; на пост-релизном наблюдении — двухнедельная капча-доля).

**Цель.** Перевести проект из «работает у меня» в «живёт постоянно»: не злись на
поисковики, не тяни `master`, дай себе данные для метрик и диагностику.

**Состав.** F-301 ✅ (поставлен в v0.2), F-303 ✅, F-304 ✅, F-305 ✅; F-302 (пин релиза) поставлен в v0.2.

**Критерии приёмки.**

- [x] Нативный режим клонирует конкретный тег релиза SearXNG, а не `master`; тег переопределяется env-переменной. — поставлено в v0.2 (F-302): апстрим git-тегов не имеет, пин — полный SHA-коммит `c7f3080aa…`, env `BATHYS_SEARXNG_REF`; doctor сверяет маркер.
- [x] Между повторными запросами к одному поисковику соблюдаются настроенные паузы с джиттером; параллельные нырки ограничены конфигом. — F-301 в v0.2: `BATHYS_SEARCH_MIN_INTERVAL`, `BATHYS_DIVE_CONCURRENCY` (джиттер отложен до реальных капч — пауза фиксированная, честно).
- [x] URL, запрещённый robots.txt, возвращает пометку отказа вместо контента (дефолт политики зафиксирован решением из хартии). — **live 2026-09-06**: LinkedIn (Disallow: /) → футер `robots-refused`, отказ кэширован; fail-open на недоступном robots; дефолт — уважение (`BATHYS_ROBOTS=0` отключает).
- [x] Локальный журнал вызовов пишется и агрегируется скриптом в метрики из `docs/operations/metrics.md`. — **live 2026-09-06**: `metrics.jsonl` (события web_search/read_url/read_urls, robots-ошибка зафиксирована), агрегатор `scripts/metrics_report.py`.
- [ ] За двухнедельный прогон доля запросов, упёршихся в капчу, ниже 5%. — ждёт двухнедельного окна живой работы (мейнтейнер).

**Риски.** Пин тега требует ручного обновления — планируем пересмотр тега раз в квартал;
вежливые паузы удлиняют холодный `deep_research` — пауза настраивается, дефолт умеренный.

**Что откладывается.** Тесты, CI, PyPI и Docker-образ (F-401–F-405) — в v1.0;
следствие: критерии приёмки v0.4 проверяются вручную, и это осознанный компромисс.

## v1.0 «Стабильный релиз» (Horizon)

**Статус: подготовка завершена 2026-09-06 (0.4.0), выпуск 1.0.0 ждёт двух внешних шагов** — публикации на PyPI (нужен токен) и первого прогона Docker-образа (в окружении разработки пока нет контейнерного движка).

**Цель.** Человек со стороны ставит Bathys одной командой и пользуется; сигнатуры
инструментов больше не меняются без мажорной версии.

**Состав.** F-401 ✅ (72 юнит-теста; e2e-смоки `scripts/*.py`), F-402 ✅ (workflow написан; запуск — после публикации репозитория), F-403 ◐ (wheel `bathys-0.4.0` собирается и проходит sanity-проверку состава; публикация ждёт токен), F-404 ◐ (Dockerfile all-in-one написан, не тестировался — нет движка в среде), F-405 ◐ (сигнатуры 4 инструментов стабильны с 0.2.0+`read_urls`; semver-политика зафиксирована в CHANGELOG).

**Критерии приёмки.**

- [ ] CI зелёный на push: линт плюс тесты на Python 3.10–3.12. — workflow `.github/workflows/ci.yml` готов (легковесный путь проверен локально: чистый venv c httpx → 72 теста OK); сам запуск — после публикации репо.
- [ ] `pip install bathys` на чистой машине поднимает сервер, который проходит smoke-проверку stdio. — wheel собирается и полон (код+compose+settings+doctor); публикация на PyPI ждёт только токена (шаги задокументированы).
- [ ] Docker-образ поднимает весь стек (Bathys + SearXNG + Chromium) одной командой. — `Dockerfile` написан (нативный режим внутри контейнера); честно: не тестировался, до первого реального `docker build` критерий не закрыт.
- [ ] Сигнатуры `deep_research` / `web_search` / `read_url` / `read_urls` заморожены и задокументированы; действует semver. — контракт `docs/contracts/mcp-tools.md` стабилен; политика: добавление опциональных параметров — minor, изменение/удаление — major.

**Риски.** API Crawl4AI нестабилен между мажорами — зависимости пинуются; образ с
Chromium и SearXNG тяжёлый (порядка гигабайта) — документируем размер и даю нативный
режим как лёгкую альтернативу.

**Что откладывается.** Всё не вошедшее (например F-204, если не успел) уезжает за 1.0
в мажорный поток — v1.0 не раздувается.

## Not-doing (не делаем)

- **Локальная LLM и синтез отчётов** — синтез остаётся за вызывающей моделью (принцип слоя данных).
- **Свой поисковый индекс** — всегда метапоиск в реальном времени.
- **UI** — веб-интерфейсы и чат-панели вне проекта.
- **Прокси-пулы и агрессивный обход капч** — только вежливая клиентская гигиена и опциональные API-движки.
- **Обязательные облачные сервисы и внешняя телеметрия** — всё опциональное выключено по умолчанию.
