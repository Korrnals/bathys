# Конкурентное позиционирование Bathys

Сопутствующие документы: [charter.md](charter.md) · [features.md](features.md) · [roadmap.md](roadmap.md).

Одной фразой: Bathys — **единый локальный поисковый сервис глубокого ресёрча для
ИИ-агентов**: один процесс, свой конвейер (метапоиск → извлечение → дистилляция под
запрос → кэш → метрики) и собственный интерфейс из четырёх инструментов, который
заменяет облачные `web-search`/`web-reader` и не тратит подписку. SearXNG и Crawl4AI
внутри — сменные движки двух ступеней конвейера, а не «сервисы, которые мы
оборачиваем» (аналогия: БД не «обёртка над B-tree»): Bathys владеет стратегией —
что искать, что читать, сколько вернуть. Он сознательно не конкурирует с Perplexica
(синтез ответов локальной LLM — вне объёма: внутри Bathys нет LLM) и не претендует
на нишу облачных API с собственным индексом.

Цены и лимиты конкурентов приведены по данным мейнтейнера и публичным страницам на
момент написания (2026-09) — перед внешним цитированием перепроверить.

## Сравнительная таблица

| Критерий | Bathys | Tavily | Firecrawl | Brave Search API | Perplexica |
|---|---|---|---|---|---|
| Где работает | Единый локальный сервис глубокого ресёрча с четырьмя инструментами (`deep_research`, `web_search`, `read_url`, `read_urls`); работает через stdio в любом MCP-клиенте (zcode, claude, cursor) | Работает из облака через REST и MCP | Работает из облака через REST, SDK и MCP | Работает из облака через REST API | Работает self-hosted через собственный веб-интерфейс |
| Цена | Не платит подпиской: тратит локальные CPU/RAM и трафик | Стоит $15–20/мес сверх ~1000 бесплатных запросов в месяц | Даёт ограниченный free tier и требует кредиты дальше | Даёт 2000 бесплатных запросов в месяц и платные тарифы дальше | Не платит деньгами, но требует хост под Ollama с моделью |

## Когда Bathys проигрывает

0. **Паритет с Tavily — статус v0.3 (обновлено 2026-09-06).** Extract-паритет
   **полный**: `read_urls` читает до 10 страниц одним вызовом под общим бюджетом,
   `read_url` — с дистилляцией под запрос, `refresh` управляет свежестью, JSON-режим
   отдаёт машиночитаемую выдачу. Search-паритет — **честно частичный**: метапоиск по
   живым движкам против платного индекса (пункты 1–2); опциональные API-движки
   (`BATHYS_ENGINE_BRAVE_KEY`) закрывают разрыв только при наличии у пользователя собственного ключа.
1. **Качество и скорость индекса.** Tavily и Brave отдают результат из собственного
   индекса — стабильно и быстро. Bathys зависит от капризов живых поисковиков:
   в момент блокировки или поломки движка выдача пустеет, а полный пайплайн
   «поиск → рендер → дистилляция» медленнее одного облачного запроса.
2. **Капчи с домашнего IP.** При агрессивной частоте Google/Bing начинают требовать
   капчи. У Tavily эта проблема решена инфраструктурой провайдера; у Bathys ответ —
   вежливый режим, ротация движков и опциональные API-движки (v0.2/v0.4), а прокси-пулы
   вне объёма. На повторяющихся блокировках Bathys деградирует.
3. **Облако и мобильность.** Bathys живёт на той машине, где запущен агент: нельзя
   дёрнуть его с телефона или из чужой среды без проброса. Tavily, Firecrawl и Brave
   доступны отовсюду по ключу.
4. **Скрейпинг как продукт.** Firecrawl умеет actions, скриншоты, обход динамических
   сценариев и структурированный extract по схеме. Bathys сознательно ограничен
   задачей «прочитать и дистиллировать» и не претендует на промышленный скрейпинг.
5. **Готовый продукт для человека.** Perplexica даёт веб-интерфейс и готовые ответы
   «из коробки». Bathys — безголовый сервис с собственным интерфейсом (четыре
   инструмента MCP); чтобы получить синтез, нужна вызывающая модель — агент-специалист
   поставляется для харнессов (agents/ + MCP-промпты), а не как веб-интерфейс для
   человека. Это осознанный отказ, а не пробел, но как пользовательский продукт
   Bathys проигрывает.

## Когда Bathys выигрывает (кратко)

Bathys выигрывает там, где агент делает десятки поисковых вызовов в день: он не
списывает подписку, сжимает контекст в 5–19 раз под конкретный запрос в честной
символьной шкале (поиск 37 549 → 1 986 симв., страница 17 063 → 2 325,
`deep_research` 35 669 → 7 508) и не показывает чужому облаку ни запросы, ни
читаемый контент.
